# ESTADIO CERO

Cómic web de ciencia ficción futbolera estilo anime: 100 jugadores, 24 horas y un planeta en juego.

- **Borrador de la historia:** [`docs/borrador.md`](docs/borrador.md)
- **Lector:** `index.html` (sitio estático, sin dependencias). Dos formatos de lectura: **Páginas** y **Cascada**.
- **Ilustraciones:** generadas por código en SVG (`js/art.js`), mezclando estilos: anime a color, manga, retro 80s, neón, acuarela, pop-art, glitch y carbón.
- **Guion en viñetas:** `js/story.js`.

Para verlo en local: `npx serve .` y abrir `http://localhost:3000`.
